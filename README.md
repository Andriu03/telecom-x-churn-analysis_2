# Telecom X – Churn Analysis

Este proyecto forma parte del desafío de análisis de datos de Telecom X y tiene como objetivo estudiar la cancelación de clientes (churn) en una empresa de telecomunicaciones utilizando Python.

A través del análisis de datos se busca identificar patrones que permitan comprender mejor los factores asociados a la cancelación del servicio.

## Objetivos del proyecto

- Explorar y comprender el conjunto de datos de clientes.
- Realizar limpieza y preparación de los datos.
- Analizar variables relacionadas con la cancelación de clientes.
- Preparar los datos para la construcción de modelos de machine learning.
- Aplicar un modelo de clasificación para predecir churn.

## Tecnologías utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Etapas del análisis

El proyecto se desarrolla en las siguientes etapas:

1. Carga y exploración inicial del dataset.
2. Limpieza y preparación de los datos.
3. Transformación de variables categóricas.
4. Análisis exploratorio de datos (EDA).
5. Preparación de los datos para machine learning.
6. Entrenamiento de un modelo de clasificación.
7. Evaluación del modelo.
